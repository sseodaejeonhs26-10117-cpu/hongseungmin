# 다시입다 — 간단한 판매·나눔 시제품

`dist/index.html`을 브라우저에서 열면 실행됩니다. HTML, CSS, JavaScript만 사용하며 설치가 필요 없습니다.

## 실행 흐름

1. 판매·나눔 등록을 선택합니다.
2. 가로·세로 600px 이상인 JPG/PNG/WebP 사진을 최소 3장 올립니다.
3. 제목, 사이즈, 설명, 상태 등급, 거래 방식을 입력합니다.
4. 검수 시연 조건을 선택하고 등록 버튼을 누릅니다.
5. 사진 부족, 추가 부위 요청, 등급 불일치 안내를 확인하거나 정상 등록합니다.
6. 등록한 글은 목록에서 확인하고 삭제할 수 있습니다.

사진은 브라우저에서 축소해 localStorage에 글과 함께 저장합니다. 브라우저 저장 공간이 부족하면 오류를 안내하고 입력을 유지합니다. 브라우저 데이터를 지우면 글도 삭제됩니다. 다른 기기나 사용자에게 공유되지 않습니다.

## 검수 범위

사진 개수와 원본 해상도만 실제 검사합니다. 얼룩, 보풀, 늘어남, 선명도, 앞면·뒷면·라벨 존재 여부는 분석하지 않습니다. 추가 촬영 및 등급 불일치는 사용자가 고른 시연 조건에 따라 표시됩니다. 실제 AI 검수 완료라고 표시하지 않습니다.

실제 서비스에는 서버, 사용자 인증, 사진 저장소, 비전 모델 연결과 개인정보 처리, 거래 기능 등이 별도로 필요합니다. 이 시제품에는 API 키나 외부 AI 호출이 없습니다.
